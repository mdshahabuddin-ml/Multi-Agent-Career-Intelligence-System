# CareerIntel AI

## Multi-Agent Career Intelligence System

CareerIntel AI is an LLM-powered multi-agent career intelligence
platform designed to help candidates research the job market,
understand career opportunities, identify skill gaps, generate
personalized application materials, and prepare for interviews.

---

## Core Capabilities

- Candidate Intelligence
- Multi-Agent Research
- Job Market Intelligence
- Opportunity Matching
- RAG-based Knowledge Retrieval
- Skill Gap Analysis
- Career Path Planning
- ATS-Friendly Resume Generation
- Cover Letter Generation
- Interview Preparation
- Application Tracking
- Career Memory
- AI Evaluation

---

## Architecture

The system uses:

- React
- FastAPI
- PostgreSQL
- LangGraph
- LLMs
- RAG
- Vector Search
- Background Workers
- Docker

---

## Major AI Systems

### 1. Candidate Intelligence

Understands:

- Resume
- Skills
- Projects
- Education
- Experience
- Career goals

### 2. Multi-Agent Research Intelligence

Specialized agents research:

- Web
- News
- Jobs
- Companies
- Academic research
- Market trends

Research is followed by evidence extraction,
verification, analysis and synthesis.

### 3. Opportunity Intelligence

Finds and ranks jobs based on candidate fit.

### 4. Career Intelligence

Provides:

- Skill gap analysis
- Career paths
- Learning recommendations

### 5. Application Intelligence

Provides:

- ATS resume generation
- Resume review
- Cover letters
- Application assistance

### 6. Interview Intelligence

Provides:

- Interview questions
- Mock interviews
- Answer evaluation
- Feedback
